# Foodie Life (Flutter Recipe App)

**Foodie Life** is a Flutter-based mobile application focused on **discovering and creating recipes**. It’s designed as a clean and beginner-friendly Flutter project that demonstrates how to build a real-world app using modern tools like **Firebase** and **Riverpod**, while keeping the code structure easy to understand.

This repository is a great starting point for Flutter learners who want to practice building UI screens, handling authentication, managing state, working with cloud data, and integrating common mobile features.

---

## Highlights

- Explore recipes with a smooth UI and category-based browsing
- Create and manage your own recipes
- Authentication flow using Firebase (login/register)
- Image selection support for recipe/user images
- Beginner-friendly project structure with reusable widgets and models
- Uses Riverpod for state management

---

## Tech Stack & Packages

### Framework
- **Flutter** (Dart)

### Backend / Services
- **Firebase Core**
- **Firebase Authentication** (session-based auth using `authStateChanges()`)
- **Cloud Firestore** (cloud database)
- **Firebase Storage** (media uploads)
- **Firebase Cloud Messaging** (push notification capability)

### State Management
- **Riverpod / flutter_riverpod**

### Local Storage & Utilities
- **SQFLite** (local database support)
- **HTTP** (API requests)
- **UUID** (unique IDs)
- **Image Picker** (pick images from device)
- **flutter_svg**, **google_fonts**, **font_awesome_flutter**, **getwidget**

---

## App Flow (High Level)

On app startup, Firebase is initialized and the app listens to authentication state:

- If the user is logged in → navigates to the main app (`TabsScreen`)
- If the user is not logged in → shows the landing/auth flow (`LandingScreen`)

Entry point: `lib/main.dart`

---

## Project Structure (Overview)

Typical folders you’ll work with:

- `lib/features/` – feature-based screens (auth, landing, etc.)
- `lib/screens/` – app screens like tabs / main navigation
- `lib/widgets/` – reusable UI components
- `lib/Models/` – data models used across the app
- `lib/Provider/` – Riverpod providers and state logic
- `lib/theme/` and `lib/constant/` – app theming and constants
- `assets/` – images and SVGs used in UI

## Firebase Setup Notes

This project includes `firebase_options.dart` (generated by FlutterFire).  
To connect your own Firebase project:

1. Create a Firebase project in the Firebase Console
2. Configure Android app (and iOS if needed)
3. Run FlutterFire configure to regenerate options:
   ```bash
   dart pub global activate flutterfire_cli
   flutterfire configure
   ```
4. Ensure Firestore/Storage/Auth rules are set appropriately for development/testing
